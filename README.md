### 🚀 About Me

I've spent **10+ years** in software, **8+ of them** building production apps in React, Next.js, JavaScript/TypeScript, HTML and CSS. I've been shipping to production nonstop since 2017.

For nearly **seven years** I was the sole frontend engineer on a Swedish B2B catering SaaS. I led its move to Next.js and owned the frontend architecture: the component system, accessibility (WCAG 2.1), performance and production monitoring with Sentry. These days I'm building a US limousine booking platform on my own in **Next.js and strict-mode TypeScript**. It went from a blank slate to launch in two months.

Before that I spent years doing full-stack work with Ruby on Rails, Node.js and PostgreSQL. That gave me a solid feel for what happens behind the UI: REST APIs, authentication and payments, including making Stripe flows hold up under failures. I'm comfortable setting technical direction, mentoring engineers and working across time zones, and I use **Claude Code** every day to ship faster without letting code quality slip.
